# 修改影响与验收记录

每次修改追加一条记录；大型任务可另建文件并在此链接。

## 记录格式

- 日期/任务/负责人：
- 用户要求、任务模式与已确认决定：
- 必须保留的内容/结构/行为：
- 本地/远端基线、目标环境/Theme/分支：
- 精确拟改文件/素材、当前负责人、授权范围：
- 与其他工作台重叠检查及协调结果：
- 影响范围：页面、共享组件、主题（含 A/B）、设备、刷新/变体/购物袋等动态状态；不涉及的注明不适用。
- 验收条件：将用户要求写成可检查结果。
- 实际变更、上传文件、回读版本、逐项页面结果及证据：
- 未验证项、原因和下一负责人：

范围变化时更新本记录。不能只检查当前打开的一个页面。
