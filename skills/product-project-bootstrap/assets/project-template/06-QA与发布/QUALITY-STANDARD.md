# 产品网站统一建设与审查标准 v1.2


以下沿用v1.1有效条款，补回原引导流程与v1.0的必要细节。G表示阶段，Q表示检查类别；它们是检查编号，不是要求用户填写的表。

### 使用与规则选择

本章维护通用质量要求；通用执行结果使用QA-CHECKLIST验收表（项目内QA-CHECKLIST），复刻证据使用REFERENCE-MAP（项目内REFERENCE-MAP）。PROJECT-BRIEF 记录本项目采用版本和差异，后续升级需比较影响，不自动改写已确认决定。

用户当前明确要求、后续修正和适用的既有授权优先。项目事实决定公开内容；任务模式决定设计自由度。默认建议不能覆盖已选定的设计或复刻基准。

| 任务模式 | 执行与验收 |
|---|---|
| 新建/重新设计 | 按产品、受众和素材组织内容，可精简重复说服；采用已选方向，没有方向时按下述引导流程探索 |
| 只改美术 | 保留信息、模块顺序及行为；只修改授权的视觉部分；检查相关功能没有回归 |
| 严格复刻 | 先通过 REFERENCE-MAP 的编码前检查；按参考双端结构、视觉、交互实现，通用优化建议不授权删减、重排或隐藏模块 |
| 局部修改/现站审查 | 根据影响范围选用检查；不自动重建整站、重做风格或创建任务 |

参考内容无依据时处理具体内容，不能默默删除容器、折叠整组卡片或虚构证据。草稿可记录待补；公开版本必须解决未核实承诺和占位。必要设计差异先记录具体前后方案，已有授权直接执行，无授权只询问该差异，继续无关工作。

### G0：引导式开工与工作空间

- 用户提供产品/参考网址及已有素材即可开始研究，不要求填写长表。创建工作空间需要用户给定路径和产品名（可用明确的工作名），不自行猜测项目根目录。
- AI整理产品信息文档和事实台账：定义、受众、场景、规格、限制、款式、包装、用法、购买顾虑及来源；能查到的信息不让用户重复收集。
- 收集外观/结构参考包和可浏览图板：正侧背、接口材质、尺寸比例、包装、款式、来源及可发布使用权。固定轮廓、比例、标志、按键和接口；缺少内部结构资料时不用生成图冒充实物拆解。
- 商业信息如价格、物流、政策暂缺可继续内部设计，列为后续依赖；产品身份冲突仅阻止依赖该身份的部分。
- 默认面向 Shopify 单品/少量产品、欧美英语、移动端优先、适度动效；用户给定平台、市场或风格时直接替换。实际配送国家必须单独核实，不能将欧美作为统一法律区域。

### G1：视觉方案与初版

- 已有选定风格则复用，不重新要求选择；严格复刻不探索替代风格。
- 新方向默认给 2–3 张实质不同的可视风格卡并推荐；用户明确数量优先。首轮推荐方向至少一套从导航到页脚的完整 Home 手机/PC 可视方案，不只首屏。用户选择另一方向时先调整整页方案。
- 风格卡记录色彩、字体层级、图标、圆角、间距、摄影光线、产品比例、素材规则及动效；具体选择唯一维护在 VISUAL-BASELINE。
- 各区块写明目的、英文核心文案、素材、布局、触发与回退；手机单独确定顺序、裁切、横滑/堆叠、导航和购买入口。
- 选定后在已授权范围落实全站框架和可浏览 Home 初版，再以每轮通常 1–3 个问题补充产品页、购买区、套餐、运营与发布信息。问题只问尚缺且影响结果的内容，不再次询问是否开始已授权工作。

### Q1：页面及状态覆盖

完整商品站计划至少包含独立 Home、产品详情、Support、品牌404，销售阶段包含政策、购物车和结账路径。Home 初版是中间里程碑，不是整站完成。

| 页面/状态 | 核对要点 |
|---|---|
| Home | 产品、用途、目标人群与下一步清楚；主要行动、场景、支持入口；复刻以参考顺序为准 |
| Product | 图库、用途、规格、包含物、用法、FAQ、价格币种、款式套餐、库存/预售、配送退换摘要和购买入口 |
| Support | 真实联系渠道、上手及排障信息、表单校验/成功/失败；显示、提交及送达分别验证 |
| 政策 | 退换、隐私、条款、配送、联系信息；法律声明按市场评估适用性。正文与入口真实，平台有政策字段时核对实际字段 |
| Cart/抽屉 | 所有已实现入口、数量修改/删除/空车、错误恢复、金额费用及结账；刷新后状态一致 |
| Checkout | 地址市场、配送费、税费、优惠、总额和可用支付；实际支付及成功/失败状态只有测试后可称通过 |
| 404 | 不存在的普通、产品、Page路径；正确404状态、统一品牌、有效恢复入口、无示例商品 |
| 其他 | 多品集合必测；搜索、账户、订单查询、密码页、营销页、应用依实际启用与范围核对，不为凑数量建空页 |

独立路由须能直接访问和刷新；首页锚点和替代 view 预览不代表正式产品/Support路由完成。未开售状态可以真实显示，不编造可购买性。

FAQ/使用指南内容应回答购买与使用障碍，可融入产品页；关于品牌按需提供真实背景，不编造创业故事。搜索启用时检查有结果、无结果、错拼及键盘操作；集合页检查缺货与无结果；账户/订单查询检查访问和找回流程。

### Q2：事实、素材与全站一致性

- 规格、认证、评价、销量、效果图、数字、专业背书引用 FACTS-CLAIMS；来源署名不证明本商品疗效。示意素材不可伪装真实客户经历。
- 价格/库存/款式/套餐以真实绑定为准；图、选择、每件款式、折扣、库存扣减、购物车与结账一致。
- 公告、商品、FAQ、购物车、政策、结账的运费和时效一致；预计发出日期与运输时间分开，退货与保修定义清楚。
- 核对本品牌外链、邮箱、地址、社交、默认配置、静态模板和生成器，不能恢复参考店身份或占位。公开邮箱、收件配置、发件配置、DNS和送达分别记录。
- 产品几何、材质、接口、包装与实际交付一致；文字和按钮在页面中实现，不烘焙进图。媒体托管与使用权分别核实。

硬件商品要在购买前说明必要的供电、安装或App依赖、实际包含物和限制；客服回复时间等承诺也须有依据。

### Q3：视觉、适配与可访问性

- 各页使用同一视觉基准，检查实际字体加载、排版、层级、媒体节奏及关键行动。局部方案不能替代全页评审。
- 每类模板完整检查实际390和1440视口；320、430、768、1024、1920重点查首屏、购买区、表格、弹层、导航、页脚，可按目标设备调整并记录。工具请求宽度与实际宽度分别记录。
- 发布审查覆盖目标浏览器及 iOS Safari/Android Chrome 真机；没有设备写未验证，模拟视口不可冒充真机。
- 无意外整页横滚、截字、遮挡；轮播局部滑动。关键控件建议44×44 CSS px；正文建议16–18px、行高1.5–1.7，这些为设计建议，不能据此擅改复刻。
- 普通文本对比度至少4.5:1、大字3:1、关键控件边界/状态3:1；不只靠颜色表意。键盘菜单/选款/FAQ/购物车可操作，弹层焦点返回，200%放大仍可用，提供所需替代文本和字幕，错误提示关联对应字段。
- 检查资源失败、低速网络及视频无法播放的回退。复刻与可访问性要求冲突时先找保真实现，确需视觉差异记录并处理，不将任一项假记通过。

新设计可用5秒理解检查产品、用途和下一步是否清楚。TICKEY仅作为产品主体、用途演示、章节层级与选购清晰度的偏好参考，不固定深色、霓虹或电子产品布局；复刻以用户提供的参考为准。

### Q4：动效与性能

- 动效级别可用M0（静态与操作反馈）、M1（轻入场与局部演示，默认）、M2（复杂叙事，另定预算）。默认轻量动效，不强迫每屏动画；保留原生滚动、即时操作反馈，连续点击不锁死或重复加购。
- 建议按钮120–200ms、折叠180–300ms、入场300–600ms；已有设计/复刻基准优先。脚本失败不能永久隐藏正文。
- 视频有封面、失败回退、静音内联自动播放；适当暂停离屏视频；循环/轮播可暂停。尊重减少动态偏好，保留必要功能。
- 流畅度通过操作与录制检查，截图不能证明无卡顿。记录设备/网络/版本和测量方式；关键购买信息不依赖精确滚动位置，轮播不自动切走用户正在操作的内容。
- 性能目标：真实数据p75 LCP≤2.5秒、INP≤200ms、CLS≤0.1，手机桌面分开；缺少实地数据时报告实验室结果和实地待补，代理指标不能冒充INP。
- 初始预算建议手机首图≤250KB、桌面≤500KB、字体总量≤200KB；视频另计。超预算依据收益和实测判断，不机械牺牲清晰度。

### Q5：集成、运营与维护

- 建立页面/共享组件/主题/A-B版本影响清单；总台上传前重新读取最新远端并合并，定向上传后回读，再检查实际前台。文件一致不证明布局与购买正确。
- 同时核对独立模板和动态刷新/选款后的内容；A/B测试不可改快照时记录缺口，不擅自结束测试或改变分流。
- 检查标题、描述、主标题、canonical、分享图、索引策略与结构化数据一致性。统计/同意管理按确认市场规划，不为测试擅装追踪。至少规划浏览、选款、加购、结账、购买事件，但规划不等于已经接通。
- 支持表单真实发送和付款按已有授权范围执行；没有授权时记未验证，不伪造结果。
- 交付可编辑源文件、素材来源、依赖、准确环境/版本、维护责任和回滚位置；不擅改已有开发目录、Live或Git状态。

### G2–G4：验收与放行

QA-CHECKLIST 是唯一通用验收结果表；复刻额外填写 REFERENCE-MAP 的逐端差异与指标，通过检查ID关联，不复制相同结果。STATUS 汇总并链接证据。

| 阶段 | 允许表述与必需证据 |
|---|---|
| G0资料与空间 | 文件/工作台创建和产品输入状态；不代表已设计 |
| G1设计与Home初版 | 选定方向、完整双端Home和可浏览初版；其余页面进度明确 |
| G2完整预览 | 范围内路由、内容、交互及启用的商品绑定；未接通事项清楚，复刻需独立结果 |
| G3发布准备 | 当前版本适用质量项、内容政策、功能、设备、性能证据；目标与回滚；核心未知不算通过 |
| G4发布后 | 明确授权、正确Live版本和匿名入口复核；密码/预览/登录限制、结账入口和实际支付分别报告 |

检查状态统一：通过 / 失败 / 未验证 / 不适用（附理由）。P0为无法访问/购买、价格款式错误等关键故障；P1为核心布局、关键政策及重大无依据承诺；P2为不影响理解交易的局部问题。当前发布范围P0/P1及核心未验证阻止放行；P2记录责任与期限。实地性能无数据按Q4明确条件报告，不伪造通过。

仅针对改动影响范围复验，无关且仍有效的证据可复用；修改后受影响证据立即标待验证。通用功能/视觉、复刻还原度、远端同步、GitHub、Live、交易状态互不替代。权重评分不得抵消关键失败。
