# 产品网站整合包 v1.3.0

统一三个网站Skill版本及执行入口，保留项目初始化只创建空间/任务的边界。增加具体模块内容与行为映射、样段视觉验证、最终平台路径测试、可编辑性验收，以及逐项证据和差异授权。

未知不能自动推成不可使用；核实问题内部记录，不擅自换素材、删评论、改视频类型或向网站添加工作状态。具体限制在任务对话中处理。原型、视觉复刻、功能与销售状态分别验收。

修复默认安装到旧目录时将同一路径误判为重复的错误。新增 `Install.ps1 -PlanOnly` 只读安装计划；替换保留备份。三个Skill必须同根安装；旧工厂批量/团队DEV版本会备份，当前包为单店便携版。

已有项目先合并执行约定并记录版本，不能覆盖事实、素材或用户决定。新Skill不能自动证明旧页面已修复。本版本安装/结构验证不等于真实站点审美和完整复刻通过。
