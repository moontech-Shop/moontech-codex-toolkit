# v1.2.4 三工作台仅初始化加固

本补丁只调整 `product-project-bootstrap` 的初始化可靠性，不启动或扩展产品研究、设计、文案、开发、上传、Git、发布或 QA 工作。

## 修复内容

- 项目模板不再提前把三个持久任务写成“已初始化”；初始状态为“待创建或核实”。
- 新建和复用任务都必须按任务 ID 幂等登记，并把真实结果同步到 `STATUS.md`。
- 项目注册、工具缺失、归档匹配、重复检查范围或启动确认存在阻塞时，只能声明项目骨架完成，不能声明完整三任务初始化完成。
- 初始化脚本在首次写入前检查所有必需目录、父目录和模板文件的类型冲突，避免发生可预见的半初始化。
- 删除旧的 `TASK-STARTERS.md` 替代方案；缺少桌面任务工具时只保留文件夹骨架并明确报告未创建持久任务。

## 兼容性

已有项目文件不会被覆盖。再次运行仍只创建缺失目录和文件；已有任务通过登记表和精确标题加项目匹配复用。旧项目若没有可靠任务登记、且可见任务列表不足以证明不存在更早任务，会先报告重复检查边界，不静默创建替代任务。
