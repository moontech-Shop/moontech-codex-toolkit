# Volt 参谋双版本 v1.0

两个独立 Skill，可任选一个或同时安装；讨论版不替换原版。

| 版本 | 使用方式 |
|---|---|
| volt-deep-advisor（原版） | 重构问题、比较方案、质疑假设，形成明确建议；保留原文。 |
| volt-discussion-advisor（讨论版） | 先理解你的考虑，每轮围绕一个主题讨论 1～3 个关键问题，充分讨论后形成判断。 |

讨论版增加：先理解再提出异议、明确事实错误直接纠正、关键证据与时效核实、反复返工的流程原因、讨论收敛条件和执行授权边界。可用“直接给建议”“信息就这些”“开始做”切换节奏。

## 安装与调用

解压双版本包，在 Codex 打开解压目录，让 Codex 将选定的完整 Skill 文件夹安装到当前使用的 skills 目录。已有同名版本时先比较，内容一致则跳过，存在差异则保留旧版并讨论替换；不要将同一 Skill 重复安装到多个根目录。安装后重新打开任务以刷新发现。

可复制以下任务给 Codex：

> 将本目录 skills 中的 volt-deep-advisor 和 volt-discussion-advisor 安装到我当前的 Codex skills 目录。保留已有原版，同名内容不同先说明差异，不覆盖。

调用原版：`使用 $volt-deep-advisor，分析这个方案并给出建议。`

调用讨论版：`使用 $volt-discussion-advisor，先和我充分讨论这个想法，再形成判断。`

二者均为独立通用 Skill，无需安装网站套件。明确指定名称可以避免选择歧义。网站开工和实施继续使用网站套件，不自动将普通页面修改变成咨询。

仓库根目录 Install.ps1 与产品网站 v1.2 ZIP 仍只安装三个网站 Skill；本双版本包按上述方式单独安装。

## 版本与验证边界

2026-09-17：首次公开收录原版和讨论版。原版仅统一文本换行，正文和界面元数据不改；讨论版是并行版本，不是原版升级替代。
结构校验与压缩包内容核对不能证明多轮对话质量；自动发现、重启加载和多轮实用效果仍需在实际任务中验证。
